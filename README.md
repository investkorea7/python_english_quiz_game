# Python English Quiz Game

## 1. 프로젝트 개요

Python으로 만든 영어 단어 객관식 퀴즈 게임입니다.

사용자는 영어 단어의 뜻을 맞히는 퀴즈를 풀 수 있으며,
새로운 퀴즈를 직접 추가하거나 기존 퀴즈 목록을 확인할 수 있습니다.

프로그램을 종료한 후 다시 실행해도 추가한 퀴즈와 최고 점수가
`state.json` 파일에 저장되어 유지됩니다.

---

## 2. 퀴즈 주제와 선정 이유

퀴즈 주제는 영어 단어의 뜻 맞히기입니다.

영어 단어 학습은 반복적으로 문제를 풀면서 단어와 뜻을 연결하는 것이 중요하기 때문에
객관식 퀴즈 형태로 구현했습니다.

Python의 클래스, 조건문, 반복문, 리스트, 파일 입출력 등을
실제 프로그램을 만들면서 연습하기에도 적합하다고 생각하여 이 주제를 선택했습니다.

---

## 3. 실행 방법

Python 3이 설치된 환경에서 프로젝트 폴더로 이동한 후 다음 명령어를 실행합니다.

```bash
python3 main.py
```

프로그램을 실행하면 다음 메뉴가 표시됩니다.

1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
6. 퀴즈 삭제

---

## 4. 주요 기능

### 퀴즈 풀기

등록된 영어 단어 퀴즈를 풀 수 있습니다.

- 풀 문제 수 선택
- 문제 순서 랜덤 출제
- 4개의 선택지 제공
- 정답 및 오답 확인
- 최종 점수 출력
- 최고 점수 저장

### 퀴즈 추가

사용자가 직접 새로운 퀴즈를 추가할 수 있습니다.

입력 항목:

- 문제
- 선택지 4개
- 정답 번호

문제나 선택지를 빈 값으로 입력할 경우 다시 입력하도록 처리했습니다.

### 퀴즈 목록

현재 등록되어 있는 모든 퀴즈의 문제와 전체 개수를 확인할 수 있습니다.

### 점수 확인

현재 저장되어 있는 최고 점수를 확인할 수 있습니다.

### 퀴즈 삭제

등록된 퀴즈 목록에서 번호를 선택하여 원하는 퀴즈를 삭제할 수 있습니다.

삭제된 내용은 `state.json`에도 저장됩니다.

## 5. 보너스 기능

## 6. 프로그램 구조

프로그램은 객체지향 방식으로 구성했습니다.

### Quiz 클래스

각 퀴즈 하나의 정보를 관리합니다.

주요 속성:

- `question`: 문제
- `choices`: 선택지 목록
- `answer`: 정답 번호

주요 메서드:

- `show()`: 문제와 선택지 출력
- `check_answer()`: 사용자의 정답 확인

### QuizGame 클래스

전체 퀴즈 게임의 동작을 관리합니다.

주요 기능:

- 메뉴 출력
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록 확인
- 최고 점수 확인
- 퀴즈 삭제

## 8. state.json 데이터 설명

`state.json`은 프로젝트 루트에 저장됩니다.

프로그램에서 추가하거나 삭제한 퀴즈와 최고 점수를 저장하며,
프로그램을 다시 실행하면 이 파일을 읽어서 이전 상태를 복원합니다.

예시 구조:

```json
{
    "best_score": 3,
    "quizzes": [
        {
            "question": "abundant의 뜻은?",
            "choices": [
                "풍부한",
                "불안한",
                "정확한",
                "평범한"
            ],
            "answer": 1
        }
    ]
}
```

- `best_score`: 최고 점수
- `quizzes`: 저장된 전체 퀴즈 목록
- `question`: 문제
- `choices`: 객관식 선택지
- `answer`: 정답 번호
